# Task-design pack

Self-initiated, AI-assisted demonstration for Dami’s portfolio. Not client work. Not an official micro1 deliverable.

The SVG mockups were authored as SVG markup for this demonstration. They were not drawn by hand by Dami.

Each task folder contains:

- `mockup.svg`
- `TASK.md`
- `SUCCESS_CRITERIA.md`
- `VERIFICATION.md`
- `reference/` — the implementation source that the live site runs

`review/REVIEW.md` critiques the CEFR gauge task.

Run the checks from the portfolio project:

```
npm ci
npm test
npx playwright test
```
