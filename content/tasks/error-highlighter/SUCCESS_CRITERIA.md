# Success criteria

1. The page says the sentences are synthetic and not a real student’s writing.
2. Sample 1 is selected. The text equivalent contains “was play” inside a `mark`, and the note list contains that phrase.
3. The canvas element is present, `aria-hidden` is true, and its box width is greater than 0.
4. Arrow Down on the listbox selects “Sample 2. Agreement”. The text equivalent then contains “She go” and “buy” in `mark` elements, with two notes.
5. End selects sample 3 and the equivalent contains “am living”. Home returns to sample 1.
6. The notes are in the text equivalent, not only painted on the canvas.
